# S-DES 算法实现

> 信息安全导论 课程作业 —— 基于 Python 的 S-DES 加解密、字符串扩展、暴力破解与封闭测试。

---

## 一、原理简介

**S-DES（Simplified DES）** 是一种教学用的简化版 DES 算法，用于帮助理解分组密码的核心思想。本项目严格按课程 PPT 的标准实现。

- **分组长度**：8-bit
- **密钥长度**：10-bit
- **加密公式**：`C = IP⁻¹( fk₂( SW( fk₁( IP(P) ) ) ) )`
- **解密公式**：`P = IP⁻¹( fk₁( SW( fk₂( IP(C) ) ) ) )`

整个算法由四个部分组成：

| 模块 | 说明 |
|------|------|
| 密钥扩展 | 用 10-bit 主密钥生成两个 8-bit 子密钥 K1、K2 |
| 初始/最终置换 | IP 和 IP⁻¹，对 8-bit 数据做位重排 |
| 轮函数 F | E/P 扩展 → 与子密钥异或 → S-box 查表 → SP 置换 |
| Feistel 结构 | 两轮 fk + 一次左右交换 SW |

**置换表、S-box 与移位规则**全部定义在 `sdes/constants.py` 中，与课程 PPT 完全一致（其中 S-box2 采用课程改动后的版本）。

## 四、操作指南（逐关）

### 第 1 关：基本加解密（GUI）

**目标**：用 GUI 完成 8-bit 明文 + 10-bit 密钥的加解密。

**操作步骤**：

```bash
python gui.py
```

在弹出的窗口中：

1. 模式选择 **8-bit 二进制**
2. 输入明文 `10111101`，密钥 `1010000010`
3. 点击 **【加密】**，结果框显示密文 `11000011`
4. 把输入改成 `11000011`，点击 **【解密】**，结果框还原为 `10111101`

**预期结果**：

| 明文 | 密钥 | 密文 |
|------|------|------|
| 10111101 | 1010000010 | 11000011 |

![第1关加密](docs/screenshots/level1_encrypt.png)

---

### 第 2 关：交叉测试

**目标**：与另一位同学的程序对同一组 (P, K) 得到相同的 C，验证算法标准化。

**操作步骤**：

1. 约定一组数据：明文 `10111101`，密钥 `1010000010`
2. 双方各自用程序加密，比对密文是否相同
3. 再互换密文，用对方密文解密，看是否能还原明文

**预期结果**：

| 步骤 | 输入 | 输出 |
|------|------|------|
| A 组加密 | P=10111101, K=1010000010 | C=11000011 |
| B 组加密 | P=10111101, K=1010000010 | C=11000011（一致 ✅） |
| B 组解密 | C=11000011, K=1010000010 | P=10111101（还原 ✅） |

![第2关交叉测试](docs/screenshots/level2_cross.png)

---

### 第 3 关：ASCII 字符串扩展

**目标**：将 S-DES 应用到 ASCII 字符串，逐字节加密。

**操作步骤**：

```bash
python gui.py
```

1. 模式选择 **ASCII 字符串**
2. 输入字符串 `This is a pen`，密钥 `1010000010`
3. 点击 **【加密】**，结果框输出二进制密文（长度 = 字符数 × 8 位）
4. 复制密文，粘贴回输入框，点击 **【解密】**，应还原 `This is a pen`

**预期结果**：

| 步骤 | 输入 | 输出 |
|------|------|------|
| 加密 | This is a pen | 112 位二进制密文 |
| 解密 | 上一步密文 | This is a pen |

![第3关字符串](docs/screenshots/level3_string.png)

---

### 第 4 关：暴力破解

**目标**：已知一组明密文对，用暴力法还原密钥，并记录耗时。

**操作步骤**：

```bash
python brute_force.py
```

按提示依次输入：

```text
请输入 8-bit 明文：10111101
请输入 10-bit 密钥：1010000010
```

**预期结果**（示例）：

```text
加密结果: 明文 10111101 + 密钥 1010000010 -> 密文 11000011

暴力破解耗时: 14.39 毫秒
找到 4 个能加密出该密文的密钥:
  0000010001
  0100010001
  1010000010
  1110000010

原始密钥 1010000010 在结果中 ✅
```

由于密钥空间只有 2¹⁰ = 1024，破解在毫秒级完成。

![第4关暴力破解](docs/screenshots/level4_brute_force.png)

---

### 第 5 关：封闭测试

**目标**：分析是否存在多个密钥对应同一密文（密钥碰撞）。

**操作步骤**：

```bash
python collision_test.py
```

**预期结果**（示例）：

```text
明文: 10111101
总密钥数: 1024
不同密文数: 254

密钥数量分布:
  一个密文对应 2 个密钥: 共有 40 个这样的密文
  一个密文对应 4 个密钥: 共有 172 个这样的密文
  一个密文对应 6 个密钥: 共有 40 个这样的密文
  一个密文对应 8 个密钥: 共有 2 个这样的密文
```

**结论**：**S-DES 中密钥不唯一**。同一个明文分组，可以被不同的密钥加密为同一个密文，因此单靠一组明密文对无法唯一确定密钥。

![第5关密钥碰撞](docs/screenshots/level5_collision.png)

## 六、模块接口说明

详细接口文档见 [`docs/api.md`](docs/api.md)。

简要说明：

| 函数 | 作用 |
|------|------|
| `sdes.cipher.encrypt(plain_bits, key_bits)` | 8-bit 明文 → 8-bit 密文 |
| `sdes.cipher.decrypt(cipher_bits, key_bits)` | 8-bit 密文 → 8-bit 明文 |
| `sdes.string_cipher.encrypt_string(text, key_bits)` | 字符串 → 二进制密文串 |
| `sdes.string_cipher.decrypt_string(binary_str, key_bits)` | 二进制密文串 → 字符串 |
| `sdes.core.key_expansion(key_10)` | 10-bit 密钥 → K1、K2 |
